Novo projeto de QA Automation no GitHub!

Estou desenvolvendo o ServeRest CRUD com BDD + Cucumber, um projeto de automação de testes de API utilizando Cucumber, TypeScript e Axios.

O objetivo é validar as principais operações de gerenciamento de usuários (CRUD) e autenticação, aplicando BDD (Behavior-Driven Development) para descrever cenários de teste de forma clara, organizada e próxima à linguagem de negócio.

O que você encontrará no projeto?

- Testes de API utilizando Cucumber e Axios.
- Cenários BDD escritos em Gherkin, com Dado, Quando e Então.
- Operações de Create, Read, Update e Delete (CRUD).
- Testes de autenticação e validação de token.
- Asserções de status HTTP, mensagens e consistência dos dados.
- Implementação dos passos de teste com TypeScript.
- Organização em Features, Step Definitions e contexto (World).
- Cenários independentes, facilitando a manutenção e a evolução da automação.

O objetivo do projeto é servir como ponto de partida para quem deseja aprender ou evoluir na área de Qualidade de Software, explorando a automação de testes de API com BDD e Cucumber.

🔗 Confira o repositório no GitHub: https://github.com/horadoqa/cucumber-serverest-crud

Este projeto ainda tem pontos de melhoria e pode evoluir para atender a cenários mais complexos e escaláveis. É apenas um START, com muito espaço para aprendizado, colaboração e evolução contínua!

Aprender, testar, compartilhar e evoluir: esse é o caminho!
